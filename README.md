# Wheel of Fortune

Лабораторная работа №1 — паттерн Цепочка обязанностей (Chain of Responsibility).

Десктопное JavaFX-приложение — игра «Колесо Фортуны».

---


# Описание

Приложение реализует простую игру «Колесо Фортуны».

Игрок начинает с фиксированного количества монет и может вращать колесо, оплачивая каждое вращение одной монетой.

После вращения случайным образом определяется один из возможных призов:

* Маленький выигрыш
* Средний выигрыш
* Большой выигрыш
* Джекпот
* Проигрыш

Для обработки результата вращения используется паттерн **Chain of Responsibility**, который позволяет передавать результат по цепочке обработчиков до тех пор, пока не будет найден подходящий обработчик.

# Функционал

| Действие            | Описание                                          |
| ------------------- | ------------------------------------------------- |
| Вращение колеса     | Стоимость одного вращения — 1 монета              |
| Анимация            | Визуальное вращение колеса через RotateTransition |
| Маленький приз      | Игрок получает +2 монеты                          |
| Средний приз        | Игрок получает +8 монет                           |
| Большой приз        | Игрок получает +20 монет                          |
| Джекпот             | Игрок получает +50 монет                          |
| Проигрыш            | Игрок ничего не получает                          |
| Пополнение          | Добавляет 5 монет                                 |
| Сброс игры          | Возвращает стартовый баланс                       |
| Отображение баланса | Текущее количество монет игрока                   |

| BigWinHandler    | Обработка большого выигрыша   |
| JackpotHandler   | Обработка джекпота            |

# Правила игры

Начальный баланс:

```text
5 монет
```

Стоимость вращения:

```text
1 монета
```

Вероятности выпадения призов:

| Результат           | Вероятность |
| ------------------- | ----------- |
| Маленький приз (+2) | 40%         |
| Средний приз (+8)   | 25%         |
| Проигрыш            | 15%         |
| Большой приз (+20)  | 15%         |
| Джекпот (+50)       | 5%          |

Если баланс становится равным нулю, игрок может:

* Пополнить баланс
* Сбросить игру
